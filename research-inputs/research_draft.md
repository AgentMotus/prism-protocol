## Core Claims Extracted
1. Human behavioral data can be represented as structured vector spaces using root-system formalisms.
2. E8/symmetry-aware architectures can improve AI retrieval, storage, training, and generalization via equivariance.
3. Dual-source data model (self-report + trained clinical reading) addresses blind spots in purely self-reported data.
4. Privacy-preserving intelligence is framed as a structural property (not only policy) via decomposition/federation.
5. Decentralized identity/data ownership is necessary for ethical AI research pipelines.

- Root-equivariant attention (symmetry-aware inference)
- Root-decomposed federated learning (distributed private training)
- Clinical compatibility matching via structured vector relations

## Limitations / Caveats

- E8-based claims should be clearly marked as framework/proposal unless benchmarked.
- Clinical usage requires strict human supervision and non-diagnostic boundaries.
- Data governance and consent mechanics must be explicit for real deployment.
